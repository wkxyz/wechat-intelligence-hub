微信 Bot 本地连接器 0.10.0

- Windows x64、Apple 芯片 Mac 和 Intel Mac 的完整便携包，包含 SQLCipher、Zstandard 和原生窗口。
- 复用已有 Reader 配置，或验证本人提供的访问材料；密钥不离开本机。
- 窗口完成宿主绑定，导出不含 token 的 MCP 配置。提供原生 JSON 工具入口。
- MCP stdio 支持状态、检索、主题、历史和回复依据；保留消息来源与覆盖缺口。
- 停止、退出、账号切换和解除绑定立即撤销授权。

包未经代码签名，不提供自动更新。先完整解压，Mac 使用附带的启动脚本，Windows 双击 exe。核对 SHA256SUMS.txt。

使用说明在包内 README.md 和 BOT-HOST.md。仅支持拥有本机工具能力的宿主；云端网页对话不会自动获得本机访问权。没有本人访问材料时不能读取数据库；不提供自动取钥或自动发送微信。
